Pasul 2 · Cerința 22pR1_ValidatorTest

Validatorul de domeniu

domeniu/Validator.java
Ce faci

Câte un if (...) return false; pentru fiecare regulă din enunț și return true; la final. Verificarea de null vine prima.

public static boolean esteValid(Anunt a) {
    if (a == null) return false;
    if (a.getTitlu() == null || a.getTitlu().trim().isEmpty()) return false;
    if (a.getDescriere() == null || a.getDescriere().trim().length() < 10) return false;
    if (a.getPret() <= 0) return false;
    if (a.getCantitate() < 1 || a.getCantitate() > 100) return false;
    if (a.getCategorie() == null) return false;
    if (a.getDataPublicare() == null || a.getDataPublicare().isAfter(LocalDate.now())) return false;
    return true;
}
Capcane

Datele nu se compară cu > sau <: folosești isAfter, isBefore, isEqual. La || pui întâi verificarea de null, altfel primești NullPointerException.

public static List<Anunt> filtreazaDisponibile(List<Anunt> sursa, double pretMaxim) {
    List<Anunt> rezultat = new ArrayList<>();   // listă NOUĂ, sursa rămâne neatinsă
    if (sursa == null) return rezultat;
    for (Anunt a : sursa) {
        if (a != null && a.getCantitate() > 0 && a.getPret() <= pretMaxim) {
            rezultat.add(a);
        }
    }
    return rezultat;
}

public static int numaraNoi(List<Anunt> sursa) {
    int nr = 0;
    if (sursa == null) return nr;
    for (Anunt a : sursa) if (a != null && a.isNou()) nr++;
    return nr;
}

public static double valoareStoc(List<Anunt> sursa) {
    double suma = 0;
    if (sursa == null) return suma;
    for (Anunt a : sursa) if (a != null && a.getCantitate() > 0) suma += a.getPret() * a.getCantitate();
    return suma;
}

Document document = documentBuilder.parse(new InputSource(new StringReader(text)));

for (int i = 0; i < nodeList.getLength(); i++) {
    Element anunt = (Element) nodeList.item(i);
    String titlu = anunt.getElementsByTagName("titlu").item(0).getTextContent();
    if (titlu.trim().isEmpty()) continue;

    String descriere = anunt.getElementsByTagName("descriere").item(0).getTextContent();
    double pret = Double.parseDouble(anunt.getElementsByTagName("pret").item(0).getTextContent());
    int cantitate = Integer.parseInt(anunt.getElementsByTagName("cantitate").item(0).getTextContent().trim());
    Categorie cat = Categorie.valueOf(anunt.getElementsByTagName("categorie").item(0).getTextContent().trim());

    boolean nou = false;                               // <nou> e opțional
    NodeList noduriNou = anunt.getElementsByTagName("nou");
    if (noduriNou.getLength() > 0) {
        nou = Boolean.parseBoolean(noduriNou.item(0).getTextContent().trim());

    anunturi.add(new Anunt(titlu, descriere, pret, cantitate, cat, nou, data));
}

Valoarea e atribut

public static double citesteCurs(String xml, String valuta) throws Exception {
    Document document = DocumentBuilderFactory.newInstance().newDocumentBuilder()
            .parse(new InputSource(new StringReader(xml)));
    NodeList rate = document.getElementsByTagName("Rate");
    for (int i = 0; i < rate.getLength(); i++) {
        Element rata = (Element) rate.item(i);
        if (rata.getAttribute("currency").equals(valuta)) {
            String text = rata.getTextContent().trim().replace(',', '.');   // acceptă și 5,1256
            return Double.parseDouble(text);
        }
    }
    return -1;   // valuta nu există
}

Cum faci un Toast

Toast-ul e mesajul mic care apare jos pe ecran câteva secunde și dispare singur. Explicat pe larg, împreună cu erorile și layout-urile: Toast, erori și layout-uri →

  1. Sus în fișier ai nevoie de import android.widget.Toast;. Dacă scrii Toast și se face roșu, apeși Alt+Enter și ți-l adaugă singur.
  2. Scrii linia acolo unde vrei să apară mesajul:
Toast.makeText(this, "Salut!", Toast.LENGTH_SHORT).show();

Cum vezi interfața unei activități

Varianta A: în editor, fără să pornești aplicația

  1. Afli ce layout are activitatea, uitându-te în onCreate. Dacă scrie ActivityAddBinding.inflate(...), layout-ul e activity_add.xml: numele se citește invers. Dacă scrie setContentView(R.layout.activity_add), numele e chiar acolo.
  2. Ctrl+click pe ActivityAddBinding sau pe R.layout.activity_add și se deschide XML-ul. Altfel îl găsești în panoul din stânga, la app → res → layout.
  3. În colțul din dreapta sus al editorului ai trei butoane mici: Code, Split, Design. Split e cel mai util: codul în stânga, ecranul desenat în dreapta. Dai click pe un element din desen și te duce la linia lui din XML.
  4. Când ai selectat un element, în dreapta apare panoul Attributes. Acolo îi schimbi id, text, inputType fără să scrii XML. Din Palette, în stânga, tragi elemente noi pe ecran.

Checklist

  • Proiectul compilează înainte să începi (altfel: compileSdk, app/build).
  • M-am uitat în teste la chei, tag-uri și atribute înainte să scriu parserele.
  • Constructorul e generat cu Alt+Insert; modelul e Serializable.
  • Nicio metodă nu a rămas fără return.
  • Parserele sar doar peste titlul gol și pun false când nou lipsește.
  • Validatorul de formular nu se oprește la prima eroare.
  • Id-urile din layout sunt exact cele din enunț; preț numberDecimal, cantitate number.
  • Adapterul are convertView == null, setTag, getTag, setText.
  • Meniul folosește if (id == R.id....); după orice schimbare a listei, notifyDataSetChanged().
