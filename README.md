# Ghid Proba DAM

Ghiduri pentru modelele de practică la proba practică DAM.

**Proba 1** (proiectul Proba1Model): https://s1lent1947.github.io/ghid-proba-dam/

- harta proiectului;
- cele 5 fișiere în care se scrie rezolvarea și de ce stă fiecare acolo;
- codul explicat pas cu pas;
- checklist pentru examen.

**Proba 3, model extins** (proiectul Model_Proba3_DAM_Extins): https://s1lent1947.github.io/ghid-proba-dam/proba3.html

- pașii de rezolvare pentru toate cele 11 cerințe, în ordinea recomandată;
- cum faci un Toast;
- cum vezi interfața unei activități (editorul de layout și emulatorul);
- cum rulezi testele și checklist pentru examen.

**Toast, erori și layout-uri**: https://s1lent1947.github.io/ghid-proba-dam/toast-erori-layout.html

- Toast: din ce bucăți e făcut, unde îl apelezi, ce pui la context;
- erori pe câmpuri cu `setError` și erori care crapă aplicația cu `try/catch`;
- layout-uri: legătura cu binding-ul, atribute, containere, ce apelezi din Java pe fiecare componentă.
